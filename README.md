
# ioBroker.verisure

Der Adapter holt in regelmäßigen Abständen Zustände über die versisure API ab und speichert diese in einzelnen States in ioBroker ab. Bisher gibt es die Möglichkeit ein Alarmsystem pro Instanz abzufragen. Sollten mehr als ein Alarmsystem in einem Account existieren, so ist dies aktuell nur über die Installation einer weiteren Instanz möglich.
